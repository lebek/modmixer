# modmixer

modmixer turns a one-line idea into a working RimWorld mod. Sprites, defs,
and a buildable folder land in your Mods directory in about a minute.

## what's here

- **start here** — install the app and ship your first mod
- **creating mods** — sprites, items, balancing
- **troubleshooting** — conflicts, load order, reading logs

If you get stuck, the in-app diagnostic agent can read your `Player.log` and
explain what broke. See [troubleshooting/logs](./troubleshooting/logs).
