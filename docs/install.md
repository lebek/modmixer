# install

Download the latest build for your platform from
[modmixer.com](https://modmixer.com).

## macOS

Open the `.dmg`, drag modmixer to Applications, and launch it. The first
launch may need a right-click → Open to bypass Gatekeeper.

## Windows

Run the installer. modmixer auto-updates from there.

## what modmixer reads

modmixer locates your RimWorld install and user data. On macOS the user data
splits across three roots — modmixer probes all of them, so no configuration
is needed.
